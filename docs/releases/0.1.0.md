# LBPPC 0.1.0

The first public release: LittleBigPlanet 3 running natively on Windows, online on LBPPC's community servers.

You need your own copy of LittleBigPlanet 3 (US, CUSA00473, version 1.28) dumped from your PS4. This release contains
no game files.

## What's in it

- **60 FPS** with frame generation (DLSS on NVIDIA RTX, FSR 3.1 everywhere else). The game itself steps 30 times a
  second, as on PS4, so physics and timing are unchanged.
- **720p to 4K and ultrawide.** The menus lay themselves out for wide screens; movies and loading screens stay 16:9.
  Ultrawide works online too.
- **Online with one account.** Create it in the launcher and play on play.lbppc.com: Refresh for levels, profiles and
  photos, and shadNet for sign-in, friends and co-op.
- **Ten million archived levels.** The community levels saved from LittleBigPlanet's original servers can be played
  again.
- **Online co-op** with your friends, with a relay through the server when your connections can't reach each other
  directly.
- **Join protection.** Only your friends can join your game, which closes the "force join" exploit that ended
  LittleBigPlanet's original community servers.
- **Friends in the launcher:** send requests, accept them, and see who's online.
- **Quit Game** in the pause menu (press it twice).
- **NVIDIA Reflex / AMD Anti-Lag 2**, and controllers out of the box, motion sensors included.
- **Make a report** in the launcher packs up everything a bug report needs, minus your passwords and user name.

## Getting started

1. Unzip the release anywhere except Program Files (for example `C:\Games\LBPPC`).
2. Start `LBPPC.exe`. Windows SmartScreen may warn about a new app: **More info**, then **Run anyway**.
3. Choose your game dump's folder and press **Play**. The first start prepares the game (about a minute), and the
   first time you see new things the shaders are built once.
4. To play online, tick **Play online**, choose a name and password, press **Create account**, and add your friends.

Full guide: https://lbppc.com/download

## Known issues

- **Online co-op is new and only lightly tested.** Starting a level very quickly after leaving another can make
  the game say the players' worlds diverged. If it happens, make a report on **both** PCs and send them to us.
- **Orange smears** can show on score bubbles and stickers, mostly with heavy particles such as rain.
- **The mouse is off** in this release. The mouse as the touchpad for touch Create Mode is planned for later.
- **The in-game friends list** may not show your friends yet. Friends in the launcher, invites and joining work.
